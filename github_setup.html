로컬 Git 설정 완료!
이미 git init 및 첫 번째 커밋이 완료된 상태입니다. 아래에 본인의 GitHub 아이디만 입력하시면 터미널 명령어와 배포 주소가 자동으로 완성됩니다.

1단계 GitHub 정보 입력

💡 아직 저장소를 안 만드셨다면, github.com/new 에서 저장소 이름을 G-telp_G(Public)로 생성해주세요.

2단계 터미널에 붙여넣을 명령어 

git remote add origin https://github.com/내아이디/G-telp_G.git
git push -u origin main

VS Code 터미널 또는 PowerShell을 열고 위 명령어를 우클릭으로 붙여넣고 엔터를 누르시면 GitHub에 업로드됩니다.

3단계 GitHub 웹사이트에서 무료 호스팅 켜기 (30초)

  1. GitHub 저장소 페이지 상단의 [Settings] 메뉴를 클릭합니다.
  2. 왼쪽 사이드바에서 [Pages] 메뉴를 클릭합니다.
  3. Build and deployment 섹션의 Branch를 main 으로 변경하고 [Save]를 누릅니다.
완성될 내 전용 웹페이지 주소: https://내아이디.github.io/G-telp_G/
