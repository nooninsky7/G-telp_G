## 📚 지원 문법 파트 (총 7개 영역 + 전범위 종합)

1. **시제 (Tense)**: 6대 진행형(과진·현진·미진·과완진·현완진·미완진) 60문항 풀이
2. **준동사 (Gerund / Infinitive)**: 동명사(-ing) vs to부정사(to V) 3:3 출제 공식
3. **가정법 (Subjunctive)**: 가정법 과거(were ~ would V) & 과거완료(had p.p. ~ would have p.p.)
4. **Should 생략 (당위성 동사원형)**: suggest, insist, recommend that + S + (should) 동사원형
5. **관계사 (Relative)**: 콤마(,) 뒤 that 불가, 선행사(사람/사물) 구분
6. **조동사 (Modal Verbs)**: must, should, may, can 등 문맥 해석
7. **연결어 (Conjunction)**: although(접속사) vs despite(전치사), however 등 논리 관계
8. **전체 종합 (All Grammar)**: 시험 전 전 문법 영역을 섞어서 10문제씩 모의고사 풀기

## 🎯 핵심 풀이 특징

* **풀기 전 스포일러 차단**: 문제 상단에 유형(과진, to부정사 등)을 띄우지 않아 실제 시험처럼 단서를 직접 찾는 훈련을 합니다.
* **보기 선택 즉시 반응**: 보기를 클릭하면 즉시 초록색(정답)/붉은색(오답)으로 바뀌며, **그 순간 비로소 `[출제 유형: 준동사 > to부정사만을 목적어로 취하는 동사]`처럼 세부 출제 유형과 G-POINT 단서 해설이 시원하게 공개**됩니다.
* **직관적인 보기 레이블**: 깔끔한 `(A)`, `(B)`, `(C)`, `(D)` 형식으로 편안하게 학습 가능.
* **➕ 문제 직접 추가**: 앞으로 공부 진도가 나가면서 새로운 기출이나 예시 문제를 상단 **[문제 추가]** 버튼으로 손쉽게 등록하여 내 문제 은행을 확장할 수 있습니다.
* **📖 전 영역 공식표 탑재**: 상단 **[공식표]** 버튼을 누르면 7개 문법 파트 전체의 핵심 공식과 팁을 탭별로 언제든 열어볼 수 있습니다.
